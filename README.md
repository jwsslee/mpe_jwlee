# 이종완의 반도체 소부장 주식투자 분석 대시보드

Streamlit + Python 개인용 반도체 소부장 리서치 앱. 아이보리·슬레이트·라벤더·세이지 디자인.

## 실행

Python 3.11 또는 3.12 권장.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Community Cloud 배포

1. 저장소 `jwsslee/mpe_jwlee`, 브랜치 `main`, 실행 파일 `app.py` 선택.
2. Advanced settings / Secrets에 `secrets.example.toml` 내용을 복사하고 실제 값을 채웁니다.
3. `APP_PASSWORD`에 충분히 긴 개인 비밀번호를 설정합니다. 서버에 저장된 키는 로그인한 세션에서만 사용할 수 있습니다.
4. 모의계좌 KEY·SECRET, 계좌 앞 8자리 `cano`, 뒤 2자리 `acnt_prdt_cd`를 문자열로 입력합니다.
5. 앱의 **모의투자 계좌 → 잔고 새로고침**으로 연결을 확인합니다.

실제 키를 GitHub·채팅에 올리지 마세요. `.streamlit/secrets.toml`은 gitignore 대상입니다.
모의계좌 API 호스트와 거래 ID는 고정되어 있으며 주문 API 코드는 없습니다.
로그인 비밀번호는 편의상 단일 사용자용 접근 제어입니다. 배포 플랫폼의 비공개 접근 제어도 사용하면 좋습니다.

## 화면

- 종합 현황: 제품·비교군 필터, 재무·시세·수급 확보 상태
- 공정별 탐색: DRAM / 3D NAND / HBM과 72개 초기 기업 목록
- 기업 분석: 주가, 실적, 현금흐름, ROE·PER·PBR·FCF·재무안정성
- 동종 기업 비교: 동일 기간 비교, 성장·수익성 산점도, 예상실적 자료
- 수급·주가: 외국인·기관·개인 누적 순매수, 이동평균
- 산업·사업 지표: 수주·가동률·CAPEX·메모리 가격 자료
- 공시·위험 점검: 공시 등록자료, FCF·부채·시세 지연 확인 조건
- 관심종목·노트: 투자 논리, 위험, 다음 확인일
- 시나리오·전략 검증: 예상 매출·순이익률·PER 민감도, 월간 모멘텀 검증
- 모의투자 계좌: 전체 페이지 잔고, 평가손익, 예수금, 종목·비교군 비중
- 데이터 관리: API 수집, 검증된 CSV 병합, ZIP 백업·복원, 데이터 사전

## API 범위와 필요한 서비스 승인

| 공급자 | 구현한 기능 | 조건 |
|---|---|---|
| 한국투자증권 모의 | 국내주식 잔고, 연속조회, 토큰 재사용 | 모의 키·SECRET + 계좌 8-2자리 |
| 한국투자증권 모의 | 투자자 수급 조회 시도 | 모의 미지원이면 명확한 오류. flows CSV로 보완 |
| KRX | KOSPI/KOSDAQ 선택일 시세 | 유가증권/코스닥 일별매매정보 서비스별 승인 |
| 공공데이터포털 | 종목별 기간 시세 | 금융위원회 주식시세정보 승인 |
| 공공데이터포털 | 연도별 요약 재무 원자료와 확인 후 매핑 | 금융위원회 기업 재무정보 승인 + 법인등록번호 |

OpenDART 직접 호출은 없습니다. 금융감독원 서버에 접속하지 않습니다.
공공데이터 재무는 원자료 기간·연결·단위·발표일·계정 대응을 확인하고 반영합니다.
KRX/공공데이터 가격은 원주가입니다. 수정주가는 별도 검증된 CSV로 보완해야 수익률과 백테스트를 계산합니다.
일부 수급·현금흐름·공시·고객 비중·수주·컨센서스는 CSV로 보완합니다. 키만으로 모든 항목이 자동 확보되지 않습니다.
실제 키가 없는 개발 환경에서는 네트워크 통합 검증을 하지 못했습니다. 서비스별 실제 연결 확인이 필요합니다.

## 저장 정책

업로드·노트·수집 자료는 세션 범위입니다. **ZIP 백업**으로 내려받아 다음 접속에서 복원하세요.
Cloud 로컬 디스크에 영구 저장된다고 가정하지 않습니다. API 키·계좌잔고·토큰은 ZIP에 포함하지 않습니다.
실제 데이터와 가상 예시는 분리되어 있으며, API 오류 시 예시로 대체하지 않습니다.
가상 예시 가격·실적은 재현 가능한 합성 데이터입니다. 72개 분류 중 12개에만 제공합니다.
기업 태그는 주력 제품의 적용 분야를 설명하는 초기 조사 목록이며 실제 고객/세대 양산 공급·현행 상장상태를 보장하지 않습니다.

## 주요 계산과 제한

`DATA_DICTIONARY.md` 참조. 연속 4분기, 공시일 기준, 연결/별도 분리, 결측값 유지.
실제 주문·자동매매는 지원하지 않습니다. 시나리오는 가정 계산이며 매수 추천이 아닙니다.
재무 기반 과거 전략 검증은 아직 제공하지 않으며 가격 모멘텀 예제만 지원합니다.
가격 모멘텀은 월초 신호 후 다음 거래일 종가 체결·그 이후 수익을 반영합니다. 생존편향·공통일자 샘플 제한이 있습니다.
